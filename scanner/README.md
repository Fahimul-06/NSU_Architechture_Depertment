# NSU Architecture QR Ticket Scanner

Java Swing scanner connected to the NSU Architecture Queue API.

## Supported scanner hardware

Most USB QR scanners operate as a keyboard. Connect the scanner, click the scan field, and scan the printed ticket. The scanner types the QR payload and sends Enter automatically.

## Run on Windows

1. Start the shared backend using `..\start-backend.bat`.
2. Double-click `run-scanner.bat`.
3. Scan a ticket generated by the connected POS.

No Maven or npm installation is required for this scanner. Java JDK 17+ is required to build it. Once built, a Java runtime is sufficient.

## Validation rules

A ticket is accepted only when the appointment exists, its token matches, it is scheduled for today, it is not cancelled/completed/absent/expired, and it has not already been scanned. Accepted tickets are changed to `CHECKED_IN` in the central datastore.

Set a different API address with:

```bat
java -Dapi.url=http://SERVER-IP:8080 -jar university-ticket-scanner.jar
```

## Dual validation modes

The rebuilt scanner supports both USB QR-ticket scanning and USB NFC student-card validation. Select the input mode at the top of the application. Early scans show the appointment details and instruct the student to arrive five minutes before the scheduled time.

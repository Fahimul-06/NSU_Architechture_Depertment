# University Faculty / Professor Dashboard

A responsive React dashboard for faculty members to manage student service appointments generated by the NFC POS system.

## Features

- Daily appointment queue
- Student name, ID, token, service and time
- Call, start, complete, absent and cancel actions
- Queue pause/resume
- Search by student, ID, token, service or status
- Service type management
- Per-student service duration
- Maximum students per day
- Class schedule management
- Service hour management
- Printable daily queue
- Responsive layout for desktop, tablet and mobile
- Demo data included

## Run

1. Install Node.js 20 or newer.
2. Open a terminal in this folder.
3. Run:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Backend integration

Replace the in-memory state in `src/App.jsx` with API calls such as:

- `GET /api/faculty/me/appointments/today`
- `PATCH /api/appointments/:id/status`
- `GET /api/faculty/me/services`
- `POST /api/faculty/me/services`
- `GET /api/faculty/me/class-schedules`
- `GET /api/faculty/me/service-hours`

The dashboard is designed to connect to the same backend and MongoDB database used by the NFC POS system.
